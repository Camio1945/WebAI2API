## 本机启动项目（非 Docker）

环境：Windows，Node v22.22.2（ABI 127），pnpm 11.10.0。

步骤：
1. `pnpm install`（会执行 postinstall 应用 camoufox-js 补丁）
2. 初始化资源。**注意 GitHub 直连极慢（~25KB/s）**，改用镜像 `https://gh-proxy.com/<github-url>` 可达 ~13MB/s：
   - better-sqlite3 预编译：`better-sqlite3-v12.5.0-node-v127-win32-x64.tar.gz`
   - Camoufox 浏览器：`camoufox-135.0.1-beta.24-win.x86_64.zip`（约 505MB）→ 解压到项目根 `camoufox/`，并写 `version.json` = `{"version":"135.0","release":"beta.24"}`
   - `GeoLite2-City.mmdb` → `camoufox/GeoLite2-City.mmdb`
3. `npm start`

### 关键坑：浏览器启动超时（safe mode）

现象：`browserType.launchPersistentContext: Timeout 180000ms exceeded`，服务进入安全模式（WebUI 200、OpenAI 接口 503）。
浏览器日志：`Failed to connect GPU process` + `RenderCompositorSWGL failed mapping default framebuffer` + `SearchEngineSelector ... defaultsConfig is undefined`。
协议层握手正常（Browser.enable 有应答），但浏览器始终不创建初始页面（无 attachedToTarget 事件）。

根因：**该环境下 Firefox 的内容进程沙箱不可用**。

解决办法：启动时加环境变量 `MOZ_DISABLE_CONTENT_SANDBOX=1`，浏览器 4~5 秒即可启动：

```bash
MOZ_DISABLE_CONTENT_SANDBOX=1 npm start
```

（若需长期生效可 `setx MOZ_DISABLE_CONTENT_SANDBOX 1`，新开终端后 `npm start` 即可。）
代价：关闭了 Firefox 内容进程沙箱，安全性降低，仅适用于本机/可信环境。

最终结果：WebUI http://localhost:46377 （200），`/v1/models` 正常返回，无鉴权 401。

## 配置自定义 API Token

- 用 `npm run genkey`（= `node scripts/genkey.js`）生成，格式 `sk-` + 48 位 hex。
- 写入 **`data/config.yaml` 的 `server.auth`**；**不要**写进 `config.example.yaml`（那是模板，且不应含真实密钥）。
- 改完必须**重启服务**才生效。
- 鉴权覆盖 `/v1/*` 与 `/admin/*`；WebUI 静态页面本身不校验（`src/server/api/index.js` 第 56-85 行），所以页面能开、但里面的接口请求会 401 并弹出登录框。
- `server.auth` 留空 = 完全关闭鉴权（`middlewares/auth.js` 里 `if (!authToken) return true`）。
- 验证方式：`curl --noproxy '*' -H "Authorization: Bearer <token>" http://127.0.0.1:46377/v1/models`（本机测试务必加 `--noproxy '*'`，否则会走环境里的 http_proxy 返回 502）。

## 坑：强杀服务后重启会卡在浏览器启动

用 TaskStop / taskkill **强杀**服务后，profile 会残留 `data/camoufoxUserData/parent.lock` 和脏状态，下次启动时浏览器握手会卡到 180s 超时并进入安全模式（表现为日志停在"启动浏览器实例..."、只有 3 个 camoufox 进程）。

恢复步骤：
1. `taskkill /F /IM camoufox.exe`
2. 删除 `data/camoufoxUserData/parent.lock`
3. 重新启动

建议日常用 WebUI 的重启功能或 Ctrl+C 优雅退出，避免强杀。
